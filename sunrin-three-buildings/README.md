# SDG 9 · 선린인터넷고 1·2·3호관 가상 통신망

수행평가 제출 시간에 건물 사이 회선이 끊겨도 학생이 제출 서버에 접속할 수 있는지 비교합니다. 1·2·3호관은 사용자에게서 받은 건물 명칭입니다. 실습 PC, 스위치, 제출 서버의 위치와 회선은 수업용 가정입니다.

## 공개 자료 확인

정보보호과 홈페이지 공개 저장소와 신입생 캠프의 학교생활 도움 앱 자료를 확인했습니다. 이 자료에서 1·2·3호관의 실별 배치나 제출 서버 위치를 확인할 수 없었습니다. [정보보호과 홈페이지 공개 저장소](https://github.com/jungvengers/sunrinsecurity) · [선린 EDCAN 신입생 캠프 공개 자료](https://github.com/kichan05/2022-EDCAN-Camp)

## 모의 배치

```text
1호관 실습 PC ── 1호관 스위치 ── 3호관 스위치 ── 3호관 제출 서버
                      │                 │
                    예비 회선         주 회선
                      │                 │
2호관 실습 PC ── 2호관 스위치 ──────────┘
```

| 회선 상태 | 1호관 PC → 제출 서버 | 2호관 PC → 제출 서버 |
| --- | --- | --- |
| 정상 | 3홉 | 3홉 |
| 1–3호관 단절 | 2호관 경유, 4홉 | 3홉 |
| 1–3호관과 2–3호관 모두 단절 | 통신 불가 | 통신 불가 |

주 회선 한 개가 끊겼을 때 예비 회선으로 두 실습실의 제출 서비스를 유지할 수 있습니다. SDG 9가 강조하는 장애에 견디는 사회기반시설을 모의 실험으로 보여주는 부분입니다.

그래프는 모든 회선을 인접 행렬에 저장합니다. 장애 상태마다 각 실습 PC에서 BFS를 실행해 별도의 최단 경로 트리를 만듭니다. 방문할 때 기록한 부모를 따라 서버까지의 최소 홉 경로를 복원합니다.

## 실행

저장소 루트에서 실행합니다.

```sh
cc -std=c17 -Wall -Wextra -pedantic sunrin-three-buildings/network.c -o sunrin-network
./sunrin-network
```

코드와 문서 작성, 실행 검증에 Codex를 사용했습니다.
