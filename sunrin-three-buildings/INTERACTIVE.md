# 선린인터넷고 가상 제출망 · 입력형

저장소 루트에서 실행합니다.

```sh
cc -std=c17 -Wall -Wextra -pedantic sunrin-three-buildings/interactive.c -o sunrin-network
./sunrin-network
```

1. 출발 호관을 고릅니다.
2. 회선 상태를 고릅니다. 정상, 1–3호관 회선 단절, 3호관 회선 모두 단절을 비교할 수 있습니다.
3. 제출 서버까지의 경로와 홉 수를 확인합니다. 트리의 부모·자식 관계가 필요하면 **트리 보기**를 선택합니다.

각 숫자는 한 줄에 하나씩 입력합니다. 예를 들어 `1 → 2`를 선택하면 1호관 실습 PC가 2호관을 거쳐 3호관 제출 서버에 도달하는 4홉 경로가 나옵니다. 정상 상태를 선택하면 3홉입니다. 두 회선이 모두 끊기면 통신 불가로 표시됩니다.

장비와 회선은 수업용 가상 설정입니다. 그래프에 회선 상태를 저장하고 BFS가 만든 최단 경로 트리로 실제 출력 경로를 계산합니다. 회선 한 개의 장애에도 제출 서비스를 유지할 수 있다는 점을 SDG 9의 인프라 복원력과 연결합니다.
