# SDG 9 · 공장 통신망 복구

공장 사무실에서 업무 서버로 가는 회선이 끊겨도 예비 회선이 있으면 통신을 이어갈 수 있습니다. 가상의 공장 통신망에서 정상 경로(2홉), 예비 경로(3홉), 두 회선이 모두 끊겼을 때의 단절을 차례로 보여줍니다. SDG 9의 사회기반시설 구축을 통신망의 장애 대응과 연결한 예제입니다.

## 실행

저장소 루트에서 실행합니다.

```sh
cc -std=c17 -Wall -Wextra -pedantic sdg9-simple/network.c -o network
./network
```

## 그래프와 트리

- **그래프**는 연결 가능한 모든 회선을 인접 행렬에 저장합니다. 회선이 있으면 1, 끊겼으면 0입니다.
- **최단 경로 트리**는 사무실에서 BFS를 실행하면서 최초로 각 장비를 발견한 부모를 기록합니다. 모든 회선을 한 홉으로 세므로 처음 발견한 경로의 홉 수가 최소입니다. 회선 상태가 바뀔 때 트리를 다시 만들고 서버에서 부모를 거슬러 최단 경로를 복원합니다.

프로젝트 평가 구성은 수업에서 제공한 「자료구조를 활용한 지속가능한 생활 문제 해결 프로젝트(수행평가)」 PPT를 참고했습니다. 코드와 설명 초안 작성 및 실행 검증에 Codex를 사용했습니다.
