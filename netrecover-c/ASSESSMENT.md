# NetRecover C 수행평가 준비 자료

수업 PPT의 통합프로젝트, 작품설명서, 제작 과정 게시 항목을 따른다. 아래 초안에 학생이 직접 실행하고 확인한 내용을 보완한다.

## 1차시 개발노트 · 주제와 탐구

학교나 재난 통신망에서 장비 또는 회선 장애가 생겼을 때 대체 경로를 찾아보는 프로젝트다. 네트워크와 자료구조를 배우는 학생이 대상이다. 여러 장비 간 연결은 무방향 가중치 그래프로 표현한다. 출발지에서 도달 가능한 장비마다 최단 경로상의 부모를 하나씩 선택하면 최단 경로 트리가 된다.

**학생 작성** — 주제를 선택한 이유와 관찰한 통신 문제를 적는다.

## 2차시 개발노트 · 구현

그래프에 회선 비용과 장애 상태를 따로 보관했다. 다익스트라는 아직 확정하지 않은 장비 중 가장 가까운 장비를 선택하고, 그 장비를 거치는 비용이 낮아지면 대상 장비의 거리와 부모를 갱신한다. 트리는 뿌리, 부모, 첫 자식, 다음 형제로 표현한다.

**학생 확인** — 교실 PC부터 학교 서버까지의 정상 경로 비용을 직접 더하고 부모 배열을 그림으로 표현한다.

## 3차시 개발노트 · 오류 검증

Linux에서 경고를 오류로 처리한 C17 빌드와 AddressSanitizer·UndefinedBehaviorSanitizer 빌드를 실행했다. 두 실행 파일 모두 장애와 복구, 동일 출발지와 목적지, 잘못된 입력과 없는 회선, 반대 방향 경로, 입력 종료를 포함한 7개 입력 흐름 검증을 통과했다.

| 예제 | 정상 비용 | 장애 후 비용 | 도달 장비 |
| --- | ---: | ---: | --- |
| 학교 회선 장애 | 6 | 10 | 6/6 → 6/6 |
| 도시 중계기 장애 | 4 | 10 | 5/5 → 4/5 |
| 완전 단절 | 6 | 통신 불가 | 6/6 → 3/6 |

**학생 확인** — 자신의 컴퓨터에서 실행하고 환경과 결과를 기록한다.

## 4차시 작품설명서 · 구성 초안

표지에 작품명, 학번, 이름, 제출일을 넣고, 다음 페이지에 목차를 작성한다.

1. 프로젝트 개요와 목적 — 장비나 회선 장애가 통신에 주는 영향을 비교한다.
2. SDGs 연계 — SDG 9는 학교 예비 회선으로 통신을 유지하는 사례다. SDG 11은 가상 재난 상황실이 주 중계기 장애 이후에도 병원까지 연결되는 사례다.
3. 자료구조와 알고리즘 — 전체 회선 그래프와 출발지에 따라 달라지는 최단 경로 트리의 역할을 설명한다.
4. 사용법과 결과 — 빌드 명령, 메뉴 입력과 위의 비용·도달 지표를 넣는다.
5. 한계 — 예제 토폴로지와 가상 비용을 사용한다. Windows·WSL에서의 실행은 직접 검증하지 않았다.
6. 참고자료와 AI 사용 내역 — 아래 항목을 포함하고 제출 전 학생이 출처를 확인한다.

## 5차시 Notion 게시 · 구성 초안

프로젝트 소개, 1~3차시 제작 노트, 실행 방법, GitHub 소스 링크를 넣는다. 학교 회선 장애 전후를 비교하는 화면과 시연 영상은 학생이 촬영해 삽입한다. 최종 소스와 실행 안내, 작품설명서, Notion 링크를 제출용으로 준비한다.
