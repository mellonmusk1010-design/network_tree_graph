# NetRecover C

학교와 도시 재난 통신망의 장애와 대체 경로를 확인하는 콘솔 프로그램입니다. 가상의 장비와 회선을 사용하며 표준 C17과 C 표준 라이브러리로 동작합니다.

## 실행

저장소 루트에서 실행합니다. Windows에서는 WSL의 GCC나 C17을 지원하는 컴파일러와 UTF-8 터미널을 사용합니다.

```sh
cc -std=c17 -Wall -Wextra -Wpedantic netrecover-c/netrecover.c -o netrecover
./netrecover
```

`1 → 4 → 5 → 0`을 한 줄에 하나씩 입력하면 학교 예제의 정상 경로, 장애 후 대체 경로, 복구 후 경로를 비교할 수 있습니다. 메뉴에서 출발·목적 장비를 바꾸거나 개별 장비와 회선에 장애를 적용할 수 있습니다.

## 자료구조와 탐색

- **그래프** — `Graph.cost[a][b]`는 두 장비 사이의 회선 비용입니다. 두 방향에 같은 값을 저장하고 회선이 없으면 0을 사용합니다. 장애 여부는 비용과 별도로 보관합니다.
- **최단 경로 트리** — `shortest_tree()`는 다익스트라로 출발지에서 각 장비까지의 최소 비용과 부모를 구합니다. 이어서 첫 자식과 다음 형제를 연결합니다. `print_branch()`가 트리 전체를 순회하며, `print_route()`는 목적지에서 부모를 따라 뿌리로 올라가 경로를 복원합니다. 같은 비용이면 먼저 발견한 부모를 유지합니다.
- **장애 비교** — 모든 장비와 회선이 정상인 상태를 기준으로 현재 상태와 비교합니다. 각 상태의 트리에서 경로 비용과 도달 장비 수를 구합니다. 도달률의 분모는 장애 장비를 포함한 전체 장비 수입니다.

장비가 V대일 때 인접 행렬은 O(V²) 공간을 사용합니다. 다익스트라의 시간은 O(V²), 트리의 추가 공간은 O(V)입니다. 예제 토폴로지는 소스에 정의되어 있습니다.
