# SDG 9 · 선린인터넷고 실습실 통신망

수행평가 제출 시간에 실습실 PC에서 과제 제출 서버로 가는 회선이 끊어졌다고 가정합니다. 예비 회선이 있으면 제출 서버에 계속 도달할 수 있는지 비교합니다. SDG 9의 **장애에 견디는 사회기반시설**을 학교 수업에서 이해하기 위한 예제입니다. 토폴로지와 과제 제출 서버는 수업용으로 가정한 것입니다.

## 학교 맥락에 참고한 자료

선린인터넷고등학교 정보보호과 홈페이지의 공개 저장소와, 정보보호과 1학년 C언어 프로젝트라고 소개된 학생 공개 사례를 확인했습니다. 첨부 수행평가 PPT의 실생활 문제 모델링 항목을 바탕으로 실습실의 과제 제출 상황을 설정했습니다. [정보보호과 홈페이지 공개 저장소](https://github.com/jungvengers/sunrinsecurity) · [1학년 C언어 프로젝트 공개 사례](https://github.com/08boramae/bluemarble)

## 실행

저장소 루트에서 실행합니다.

```sh
cc -std=c17 -Wall -Wextra -pedantic sunrin-sdg9/network.c -o sunrin-network
./sunrin-network
```

| 상황 | 실습실 PC에서 과제 제출 서버까지 |
| --- | --- |
| 정상 | 실습실 주 스위치를 거쳐 2홉 |
| 주 회선 장애 | 실습실과 복도의 예비 스위치를 거쳐 3홉 |
| 예비 회선도 장애 | 통신 불가 |

**그래프**는 장비 사이 회선을 저장합니다. **최단 경로 트리**는 실습실 PC에서 BFS를 실행해 각 장비에 처음 도달한 부모를 기록합니다. 회선이 끊길 때마다 트리를 다시 만들고, 서버에서 부모를 거슬러 최소 홉 경로를 복원합니다.

코드와 설명 작성, 실행 검증에 Codex를 사용했습니다.
